Decisions

4 decisions

Chosen D1 · A CharacterLoadout per character: the weapon list and the reward per level.

Chosen D2 · Owned weapons are derived from the shared completed levels and the character's rewards; the save does not change.

Chosen D3 · Now, not in 060h: WeaponDef<in O : MegaPlayer>. Megaman's defs take Megaman; a def that takes MegaPlayer is shared. The look fields move into a per-character WeaponLook in the loadout.

Chosen D4 · Fix it here: every player class gives shooting, so enemies see X's and Proto Man's shots.

Also in scope, no decision needed: movesBlockedWhileFiring becomes private, read through a function, so no code can change a shared def.
