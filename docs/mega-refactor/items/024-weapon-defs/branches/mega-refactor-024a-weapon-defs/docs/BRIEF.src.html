Item 024 · Branch 024a · Objectives O8, O1 · approved 2026-11-14

Each weapon in one definition

Megaman's 10 weapons become WeaponDef objects with stable ids. The data and the fire code of each weapon move out of the when blocks on MegamanWeapon into its definition.

In play: Nothing changes. This is a refactor.

Before and after

One weapon is in one place, not spread over 8 files

Code sketch

The handler stops building weapons in a when

Today, MegamanWeaponsHandler:

private fun createWeaponEntry(weapon: MegamanWeapon) = when (weapon) {
    MegamanWeapon.NEEDLE_SPIN -> object : MegaWeaponHandler(cooldown = Timer(0.25f), normalCost = { 2 }, ...) { ... }
    ...
}
when (weapon) {
    MegamanWeapon.NEEDLE_SPIN -> spinNeedles()
    ...
}

After:

val NEEDLE_SPIN = WeaponDef(
    id = "needle_spin",
    cooldown = 0.25f,
    normalCost = 2,
    blocksMovesWhileFiring = true,
    fire = ::fireNeedleSpin,
)
states.put(weapon, weapon.newState())
weapon.fire(megaman, states[weapon], stat)

A behavior, today and after:

megaman.currentWeapon == MegamanWeapon.NEEDLE_SPIN && megaman.shooting
megaman.currentWeapon.blocksMovesWhileFiring && megaman.shooting

Decisions

4 decisions

The ids are today's enum names in lower case (mega_buster). So the atlas keys, the region names, the --weapons values and the display text stay the same strings. The save does not store weapons.

Chosen D1 · A WeaponDef object with a string id; the enum goes.

Chosen D2 · WeaponDef.newState() makes one WeaponState per player; 4 weapons have a state subclass.

Chosen D3 · All single-weapon rules become def hooks now (the owner chose this over the recommendation).

Chosen D4 · 024a refactor only; 024b the loadout per character and the workarounds; then 060h.

Risks

The fire code moves, so the step order must stay

  • risk Step order. Cooldown, pre-shoot, fire, post-shoot and ammo stay in fireWeapon. A test fires each weapon through the public flow.
  • risk Derived strings. A wrong id breaks an atlas lookup at run time. A test compares every derived string with today's string.
  • risk 060d overlap. GroundSlideBehavior changes in both branches. This branch changes it last, after 060d merges if it can.
