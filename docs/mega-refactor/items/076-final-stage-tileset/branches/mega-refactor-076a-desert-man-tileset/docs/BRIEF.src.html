Desert Man tileset

Desert Man gets one new, original tileset, built from the five accepted art phases (rock, steel, props, sandstone, oasis), and its map is repainted with it. No code changes.

In play: every tile of Desert Man looks new. Blocks, ladders, spikes, water and gates stay where they are.

Decisions

Six decisions, all on the recommendation

Chosen D1: draw the 2 gate-column tiles in this branch, so the map paints no old art.

Chosen D2: a calmer bloom head, so it does not read as a pickup.

Chosen D3: the generator and remap script and its README are temporary files in temp/076-desert-tiles/tools/, not in git changed 2026-11-17; Tiled automapping is a backlog candidate.

Chosen D4: the new back wall is opaque (86 cells no longer show the sunset faintly through).

Chosen D5: the map uses only the new tileset.

Chosen D6: check the spikes under water at the play test, and fix them in this branch if needed.

Risks

A wrong tile in a cell is the main risk

  • risk Wrong tile. A missing edge or a wrong grid-position tile. The script fails on any unmapped gid; previews of every room; the play test.
  • risk Other map data. The script changes only the tileset list and the 5 layer CSVs; a check proves all other lines are unchanged.
  • risk Hand edits later. The rock and soil fill use a 2x2 block by cell parity; a hand edit in Tiled must follow the rule in the README.
