Desert Man backgrounds

The three accepted background drafts go into the game: an animated dawn sky at the start, and an animated sunset with heat haze after the cave. The three frames move to a new atlas, because they do not fit Backgrounds6 with the Basic packer.

In play: new, animated skies in Desert Man. Other levels look the same.

Before and after

Three regions move to a new atlas

Code sketch

SunriseHills becomes an AnimatedBackground

Today, BackgroundLayerBuilder:

"SunriseHills" pairTo {
    Background(game = params.game, it.name, ...,
        model = assets.getTextureRegion(TextureAsset.BACKGROUNDS_6.source, "SunriseHills"), ...)
}

After (the other values as today):

"SunriseHills" pairTo {
    AnimatedBackground(game = params.game, it.name, ...,
        model = assets.getTextureRegion(TextureAsset.BACKGROUNDS_7.source, "SunriseHills"),
        animRows = 2, animColumns = 4, duration = 0.2f, ...)
}

Decisions

Two decisions

The atlas rule is yours already: Basic only, and a new atlas when frames do not fit.

Chosen D2: only the 3 changed regions move to Backgrounds7.

Chosen D3: accept the 20 px height difference; check at the room 14 gate in the play test.

Risks

The repack is the main risk

  • risk Repack. A kept region could change. A script compares the names and pixels of all 12.
  • risk Silhouette jump. The two hill layers differ by 20 px. The swap happens while the dark room 14 comes into view, so no jump can show (review, 2026-11-17).
  • risk Memory. One more 1024x1988 texture loads at start.
