Respawn routine

Replace the chain of 5 events and 2 screen handlers that runs a death and a respawn with one RespawnRoutine. Its steps run in a fixed order, which you can read in one file. It reuses Routine and Step from the engine, the same types that the boss fights use.

In playNothing changes, except one music fix: in SMB3_1, a respawn in a room with no music now plays the level music, not the music of the room where you died.

Decisions answered 2026-11-06: all as recommended

D1

One branch or two?

The item has two parts: the routine, and splitting PLAYER_SPAWN into a per-player event and a LEVEL_RESET event, which moves 24 listeners.

ChosenTwo branches into master038a: the routine, with the same events. 038b: the split. Each one is safe to ship alone.
One branchBoth parts at once. The diff is larger, and a frame problem is harder to trace to one part.
Two branches, parent branchUse this only if 038a must not ship alone. It need not.
D2

An interface for the routine now?

The item proposed one, so that co-op (047) can add its own routine. You also asked whether an interface is enough when players can join and leave during play.

ChosenNo interface yetA concrete class. 047 designs the co-op shape when it has a real second caller (rule O1-R5).
Interface nowA RespawnFlow interface with one single-player implementation, and no second caller yet.
D3

Does the routine also own the death half?

ChosenDeath and respawnSteps 1 to 6 in one owner. The level start enters at step 4.
Respawn onlySteps 4 to 6. PlayerDeathEventHandler and 2 event hand-offs stay.

Risks

  • Frame timing. PLAYER_SPAWN arrives one frame after the reset, because the engine queues the spawn. Entities spawned in that frame can be culled by it. The routine keeps these frames, and a test checks them.
  • Overlap with 081a. That branch moves Megaman.onSpawn and onDestroy, which send 2 of the events. This branch does not change those lines, but the branch that merges second must rebase.
  • Pause and game over. A death while paused must still resume the game. When no lives are left, no respawn step may run.
