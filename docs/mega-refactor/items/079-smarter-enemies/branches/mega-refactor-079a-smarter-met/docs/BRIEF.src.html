Smarter Met

The Met stops at death pits, jumps when a jump is safe and useful, and reacts to charged shots: a stagger with the helmet up, and on the 3rd charged hit the helmet breaks and the Met goes desperate. A shared GroundProbe answers "is the ground safe here?" for any walking enemy.

In play: Mets no longer fall into pits; they jump gaps and steps; a charged shot pops the helmet up (higher for a full charge); 3 charged hits break it; hard-mode Mets chase and dodge. run_only Mets (the GutsTank fight) do not change.

Before and after

3 timed states become 7 states that read the ground and the hits

Code sketch

The Met asks the probe before each run step

Today, Met in RUNNING:

if (!body.isSensing(BodySense.FEET_ON_GROUND)) {
    behavior = MetBehavior.SHIELDING
    return@add
}
body.physics.velocity.x = runImpulse

After:

val ahead = groundProbe.groundAhead(body, facing, direction, maxDrop = MAX_SAFE_DROP)
when {
    ahead.safe -> body.physics.velocity.x = runImpulse
    jumpPlanner.plan(body, jumpGoal(), out = jump) -> startJump(jump)
    else -> stopAndTurn()
}

A charged hit goes to one handler, from the helmet fixture or from the body:

shieldFixture.setReceiver(Receivers.HIT_BY_PROJECTILE) { if (it is ChargedShot) onChargedHit(it) }

private fun onChargedHit(shot: ChargedShot) {
    helmetHits++
    if (helmetHits >= HELMET_HITS_TO_BREAK) breakHelmet() else stagger(full = shot.fullyCharged)
}

Decisions

3 decisions, answered

changed 2026-11-18 Round 1, owner: the stagger is now a stun. The helmet is its own entity (MetHelmet: body, shield, damager, no block collision) that flies up, follows the head and lands back on it. The landing ends the stun, within a minimum of 0.89 s and a maximum of 1.77 s (derived from the helmet flight; see NOTES.md). The stunned Met shows spinning stars; the landing pushes it down and back up. The airborne helmet hurts Mega Man, and a charged hit on it counts toward the 3.

The main design is set from your answers: stagger with no damage while the helmet is on, Claude draws the art, one world probe, the proposed jump rules, a smarter hard mode. These details are still open.

D1 Chosen It bounces off with the dink, as today, and counts toward the 3 hits.

D2 Chosen A palette copy of each new Met frame.

D3 Chosen About 1 shot in 3.

Risks

The turned Met is the case most likely to break

  • risk 4 gravity directions. No live map turns a Met, but the code supports it. The probe and the jump arcs work in the Met's local frame; a test room has a Met on a ceiling and on a wall.
  • risk Gauntlet waves. A Met that jumps away or turns at a pit can slow a wave. It still dies to every shot, so a wave cannot lock.
  • risk Atlas repack. New frames go into Enemies1. A script checks that every old region keeps its name and pixels.
