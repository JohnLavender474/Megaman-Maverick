Decisions

4 decisions

The body code holds shared parts and Megaman's own parts in one function. These questions set where the line goes.

D1 · What shape does the shared body take?

Chosen One playerBody(params) builder with hooks.

D2 · Does X move onto the shared run and body too?

Chosen No. X keeps his own body and run.

D3 · Where does the gravity table live?

Chosen A PlayerGravity component in players/.

D4 · The Moon Man speed check (a level-name check, against rule O7-R3)?

Chosen Keep it in Megaman's own max-speed parameter.

Risks

A missed line changes Mega's feel

  • risk Fixture order. The order of the fixtures sets the order of the contacts. A new test compares Megaman's fixtures (type, size, order) with the values before the branch.
  • risk The body pre-step. Gravity, slide height, clamps, ice and water are many small lines. A missed line changes the feel only in some rooms. Tests for the gravity table per direction, plus control checks in water, ice and each gravity direction.
  • risk No body tests today. The run has MegamanRunTest; the body has none. The branch adds them before it moves the code.
