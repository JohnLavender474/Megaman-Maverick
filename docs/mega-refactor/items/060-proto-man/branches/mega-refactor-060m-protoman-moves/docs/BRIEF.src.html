Proto Man: wall slide, air dash, swim

Proto Man gets Megaman's wall slide (with the wall jump), air dash and swim, through the shared players/ code. The swim moves into players/ first. A Fable 5.2 art agent draws the new frames.

In play: Proto Man slides down walls, kicks off them, dashes once per jump and swims. Megaman and X play the same.

2 moves are calls, the swim moves first

Code sketch

Proto Man's new behaviors

WALL_SLIDING pairTo playerWallSlideBehavior(this, WallSlideParams(
    blocked = { sabre.active || wallSlideNotAllowed() },
    onAct = { frictionOnSelf = ProtomanValues.WALL_SLIDE_FRICTION }, ...)),
AIR_DASHING pairTo playerAirDashBehavior(this, AirDashParams(
    canStart = { aTask == AIR_DASH && airDashInputJustPressed(this) },
    speed = { if (inWater) WATER_AIR_DASH_VEL else AIR_DASH_VEL }, ...)),
SWIMMING pairTo playerSwimBehavior(this, SwimParams(   // new, Megaman calls it too
    impulse = { ProtomanValues.SWIM_VEL }, ...))
