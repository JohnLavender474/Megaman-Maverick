Code sketch

Proto Man is mostly values

class Protoman(services: MegaServices) : MegaPlayer(services), IScalableGravityEntity {
    override val cameraFocusHeight = ProtomanValues.BODY_HEIGHT
    override var direction: Direction   // signs the gravity table, as Megaman
    internal override fun defineBodyComponent() = playerBody(this, PlayerBodyParams(width = ..., height = ...))
    internal override fun defineBehaviorsComponent() =
        BehaviorsComponent().apply { addBehavior(JUMPING, playerJumpBehavior(this@Protoman, jumpParams)) }
    internal override fun defineControllerComponent() = ControllerComponent(
        MegaControllerButton.LEFT pairTo playerRunButton(this, Facing.LEFT, runParams, { false }, {}), ...)
}

Decisions

4 decisions

Small calls follow Megaman: the plain jump frame, Megaman's idle timing for the scarf flick, the blue beam until 060e, and no slide on DOWN + A until 060d.

D1 · When does the step frame show?

Chosen As Megaman: at a stop, a landing and the spawn.

D2 · How does the sheet become an atlas, now and in later branches?

Chosen A prep script, the prepared sheet and the YAML in utils/sprite_slicer/sheets/.

D3 · The sheet faces left; Megaman's frames face right. Where does the flip go?

Chosen Mirror the frames in the prep step.

D4 · Where do his walk, jump and gravity values come from?

Chosen His own ProtomanValues, with Megaman's numbers to start.
