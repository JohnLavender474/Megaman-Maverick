Decisions

D1. The ladder in room1 blocks X

The route goes down a ladder at tile 62. Only a climbing body passes its top, and phase 1 has no climb, so X cannot finish the level.

  • Recommended: a temporary rule with a TODO: X drops through a ladder top while DOWN is held.
  • Add climb to phase 1.
  • Leave it blocked until climb comes.

D2. Charge feedback

X has no charge art, and D1000 takes damage only from a full charge.

  • Recommended: a color flash on X in code, with a TODO for real art.
  • The charge sound only.
  • Recolored charge frames from a script, now.

D3. Movement values

The X6 values in Maverick units: walk 3.75 tiles/s, jump about 2.05 tiles high. Megaman runs at 6 tiles/s. The map is at the X6 scale.

  • Recommended: use the X6 values as they are, in one values file, and tune after the play test.
  • Scale them toward Megaman's feel now.

Already decided: the weapon reads in the screens use is Megaman workarounds with TODOs for 024. The stand shot uses the land_shoot pose, and the jump strip splits into rise and fall frames.

Risks

  • The jumpBehavior parameters touch Megaman's jump. A jump-height test runs before and after, and there is a control play check.
  • A swap while a player is in the engine. A fail-fast check guards it.
  • 4 screen casts crash with X today (HUD, weapon-energy drop, beam-out, progress reset). Each gets a fix and a test.
