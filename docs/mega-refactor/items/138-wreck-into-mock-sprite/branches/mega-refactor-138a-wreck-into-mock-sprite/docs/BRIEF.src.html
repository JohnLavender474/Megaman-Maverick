Decisions

Three decisions

The wrecks today sit on 32 px points with the size and the anchor in a code table. MockSpriteEntity's own behavior has no user.

D1 Chosen The sprite fills the object rect.

D2 Chosen Rename to MapSprite.

D3 Chosen Drop the old mock behavior.

Risks

A wreck can move a few pixels

  • risk A wreck moves. The new rects are computed from what the game draws today; a test checks the sprite bounds, the region and the draw order.
  • risk Draw order. The mock draws in front (PLAYGROUND 0); the map sprite keeps the wreck's BACKGROUND 1, so the wrecks stay behind X.
  • risk Small conflict with 137a in the smoke-test tag list (next lines); simple to resolve.
