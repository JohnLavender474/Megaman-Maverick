Stable, but its Kotlin 2.0.21 compiler cannot read 2.3 library metadata. Konsist. No type resolution, so it has the same gap as the text scan. Faster check, no protection later. Main sources only. Tests make their own java.util.Random on purpose. Also test sources, with exceptions for the test helpers.

Risks
