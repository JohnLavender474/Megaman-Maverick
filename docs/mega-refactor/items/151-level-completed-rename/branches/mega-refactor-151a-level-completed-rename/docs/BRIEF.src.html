Item 151 · Branch 151a · Objectives O1 · approved 2026-11-11

Level progress says "completed", not "defeated"

The saved level progress of GameState, its listener, the player progress component and the MegaPlayer hook are renamed from "defeated" to "completed". The word "defeated" stays with bosses.

In play: Nothing changes.

Before and after

The same chain, with one word changed on each link

Code sketch

The hook that started the nitpick

Today, MegaPlayer:

protected open fun onLevelDefeated(level: LevelDefinition) {}

internal fun definePlayerProgressComponent() = PlayerProgressComponent(
    onLevelDefeated = { level -> onLevelDefeated(level) },
    ...

After:

protected open fun onLevelCompleted(level: LevelDefinition) {}

internal fun definePlayerProgressComponent() = PlayerProgressComponent(
    onLevelCompleted = { level -> onLevelCompleted(level) },
    ...

Decisions

Three decisions, answered before the branch

The review of the edge cases asked them, and the owner answered "Go with your recommendations".

Chosen D1 · allLevelsDefeated has no callers and can never be true (the ending never records the last stage). It is deleted, not renamed.

Chosen D2 · The 3 exception messages in GameState that say "Levels defeated" for heart tanks, health tanks and enhancements get the right noun.

Chosen D3 · The planned JSON save key in the 007 notes becomes levelsCompleted, so the future file matches the code.

Risks

A text replace would hit the boss vocabulary

  • risk Over-replace. "defeated" is also an atlas key, an animation key, a Tiled prop part, an event and a lock reason. The branch renames symbols only, and a grep checks that the boss files and the assets have no diff.
  • risk A later override. The hook is protected open. 060c adds Proto Man code under MegaPlayer later and must use the new name.
